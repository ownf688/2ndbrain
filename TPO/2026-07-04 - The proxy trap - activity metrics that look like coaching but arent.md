# The proxy trap: activity metrics that look like coaching but aren't

> **The take:** The more an activity metric looks like it measures coaching, the more dangerous it is when it doesn't. Agenda edits, meeting counts, and Slack activity create a false floor of competence.

## Context (private, not for publication)
During the first Manager Health Pulse, investigated whether Windmill 1:1 agenda edits (some managers had 500-1,000+) could proxy for coaching quality. Spot-checked Owen/Lynnette agendas: content was operational checklists (litigation sign-offs, budget approvals, project status). High edits = good task management, not developmental feedback. This led to a standing rule: agenda edits are not feedback.

## The insight
People teams love dashboards. We track 1:1 completion rates, agenda engagement scores, Slack message volume, login frequency. These metrics feel rigorous because they're quantified, but they measure activity, not impact.

The dangerous ones are the metrics that look closest to what you actually want to measure. Agenda edits look like meeting preparation and engagement. Message volume looks like collaboration. 1:1 counts look like coaching cadence. Each one creates a plausible story that obscures the real question: is this manager developing their people?

The only reliable signal I've found is the feedback artifact itself -- a documented observation about someone's performance, skills, or values, written close to the moment it happened. Everything else is a proxy, and proxies get gamed or misread.

When you build a manager health dashboard, start with the output you actually want (documented coaching), then add context metrics (are they meeting? are they engaged?). Never let the context metrics substitute for the output metric.

## Evidence
- Managers with 500+ agenda edits and zero feedback entries
- Agenda content audit: operational task lists, not coaching observations
- Standing rule created: do not count agenda edits as a feedback proxy
