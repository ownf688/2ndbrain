# O11 - Fixed-price rescue/hardening of vibe-coded apps (Lovable/Replit/Bolt/Base44/v0 -> production Supabase + React)

All sources seen 2026-10-03.

## 1. Paid demand today? PASS
- FACT: Agencies sell this as a named service. Wavect "Vibe Code Rescue" (https://wavect.io/services/vibe-coding-rescue/), MetaCTO "Vibe Rescue" (https://www.metacto.com/solutions/product-development/vibe-rescue), Pragmatic Coders rescue service (https://www.pragmaticcoders.com/?p=21920).
- FACT: Upwork job posts for "AI App Launch Specialist" covering audits, Stripe, deployment, security (https://www.upwork.com/freelance-jobs/apply/App-Launch-Specialist-Needed_~022030684955894588033/).
- FACT: Dozens of Fiverr gigs exist for exactly this (links in check 3).

## 2. Raw material free? FAIL (soft)
- FACT: Inputs are the client's own repo plus free tools: Supabase Security Advisor and database linter are free in the dashboard, with weekly security emails (https://supabase.com/blog/hardening-supabase). Advisories are open source.
- OPINION: The output (RLS policies, auth fixes, Stripe wiring, tests) is standard work any competent Supabase/React dev can do. No data or access moat.

## 4. Big company switches it on free? FAIL
- FACT: Lovable has built-in Basic scan (RLS linting, schema review, dependency audit) and Deep scan (agentic code review, 2-4 min) (https://docs.lovable.dev/features/security ; https://lovable.dev/blog/how-lovable-protects-your-apps-automatically).
- FACT: Lovable Payments launched 13 Apr 2026: Stripe/Paddle/Shopify, subscriptions, VAT in 200+ countries (https://www.createwith.com/tool/lovable/updates/lovable-launches-payments-feature-with-vat-support-for-200-countries).
- FACT: Replit Security Agent runs Semgrep + HoundDog scans before publish, one-click fixes; dependency scans free and automatic (https://docs.replit.com/features/security/project-security-center ; https://semgrep.dev/blog/2025/replit-and-semgrep-secure-vibe-coding).
- FACT: Supabase Security Advisor free, one-click fixes, plus free AI RLS assistant (https://supabase.com/blog/hardening-supabase).
- OPINION: Security and payments, two of the five pillars, are already being absorbed by the platforms. Remaining work (tests, deployment) is next on their roadmaps.

## 5. Licence / ToS? PASS
- REASONABLE GUESS: No licence needed for software consulting. Payments work uses Stripe's own compliance; no FCA authorisation needed for integrating a PSP. Not found: any platform rule against it.

## 6. First 10 buyers online? PASS
- FACT: Channels exist: Lovable Experts directory (https://lovable.dev/partners/experts), Fiverr/Upwork, MentorCruise, vibecoding.app agency directory (https://vibecoding.app/agencies), Lovable/Replit Discord and Reddit communities (REASONABLE GUESS on community size, not checked).

## 7. Free AI does it within 2 years? FAIL (likely)
- FACT: Lovable Deep scan and Replit Security Agent are already AI reviewers that propose and apply fixes (links above).
- OPINION: Claude Code/Cursor already do much of the hardening for anyone semi-technical; for non-technical founders, the builders themselves are closing the gap. The residual market is human accountability and messy edge cases, which pushes toward agency-scale work, not a solo fixed-price product.

## VERDICT: KILLED
Failed: 3 (crowded, $50 Fiverr gigs to $50k agencies, plus Lovable's own partner directory), 4 (Lovable scans + payments, Replit Security Agent, Supabase Security Advisor all free), 7 (likely), 2 (soft).
Demand is real (check 1 passes), so it could work as side freelance income via the Lovable Experts directory, but not as a defensible business. Biggest risk if pursued anyway: platforms absorb each pillar (security done, payments done) leaving only bespoke, hourly work.
