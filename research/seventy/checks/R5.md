# R5. Fixed-price "first People tool" build sprint (evenings only), £1,500-3,000

Idea: a Head of People at a 50-500-person scale-up pays a fixed fee for one internal tool (1:1 tracker, pipeline dashboard) built with Claude Code on their HRIS/ATS data. No feedback-chasing bots (Nudge overlap). All evidence seen 2026-10-04.

## Kill checks
1. **Someone pays today? PASS (weak).** FACT: Contra sellers list fixed-price ops/internal-tool work: "Business Operations Blueprint" $1,497, "AI-Powered Operations System" $399, "Workflow Automation Setup" $199 (search summary of https://contra.com/kim_barrazona_zk1t8ne3/services and https://contra.com/muratcankoylan/services). Upwork lists People Ops consultants doing HiBob/HRIS automation (https://www.upwork.com/hire/organizational-development-consultant/eg/). A $4,200 Claude Code CRM build exists as one CLAIMED anecdote (round1_genC.md, E9). No priced HR-specific build sprint found.
2. **Raw material free, output easy? FAIL.** FACT: Remote's own People team built a case tracker and org-health dashboard themselves by connecting Claude to workforce data via the Remote MCP (https://remote.com/en-gb/blog/build-hr-tools-with-ai). Lovable markets HR apps (onboarding, directories, request portals) directly to HR teams "without waiting on engineering or the HRIS roadmap" (https://lovable.dev/for/hr). The buyer's data is their own; the build is now a DIY job.
3. **Rivals at a similar price? FAIL.** Generic ops/internal-tool freelancers sell at $199-1,497 on Contra (above); Fiverr from $20 (O15 kill, `../../killed.md`); low-code agencies such as LowCode Agency (https://www.lowcode.agency/blog/real-apps-built-with-lovable, price not found). The only difference is "HR know-how", which is niche/brand only. This repeats the O15 reason with no new evidence against it.
4. **Big company switches it on free? UNCLEAR (leans FAIL).** FACT: Remote ships an MCP so customers build their own tools (link above); Lovable has an HR landing page. ATS vendors ship agents (Workable agent with free credits, round1_genC.md E11). REASONABLE GUESS: HiBob/Workable will keep adding dashboards and agents free to their installed base.
5. **Licence / ToS? PASS.** No licence needed to build software. GDPR: the user would process client employee data, so a data processing agreement is needed. Not a licence.
6. **First 10 buyers online? PASS (unproven).** HR-leaders newsletter, LinkedIn, Contra. Newsletter size unknown.
7. **Free AI does it within 2 years? FAIL.** The Remote case above shows a People team already getting the same result from Claude without a contractor. Claude/Lovable lower the skill bar every release.
8. **Fits limits? UNCLEAR.** Build is async, but discovery calls, access to HRIS admin and the maintenance tail sit in client working hours. Day-job conflict: selling builds that resemble NALA tools raises IP/moonlighting questions; vault skills are shared via the nala-brain repo (mixed IP, round1_genC.md).

## Verdict: KILLED (2, 3, 7 FAIL; 4, 8 UNCLEAR)
OPINION: a build sprint is a repeat of O15 with an HR label. The strongest evidence against is that the target buyer (a People team) is the one publicly building these tools themselves with Claude.

## Evidence for each rubric criterion (for a scorer)
- Proof people pay: close substitutes only (generic ops builds $199-1,497 on Contra). No HR-specific seller found. Lower band.
- How empty: crowded with generic builders; free DIY route (Lovable, Claude + MCP).
- Timing: live AI-build wave, no dated trigger. Wave makes DIY easier, so it cuts against.
- Size: LeftClick (AI automation agency) claims $100k/month, CLAIMED, and the money is mostly its course (`../../millionaires/cases/services-agencies.md`). No HR-build comparable found.
- Speed to first sale: one warm buyer in 2 weeks possible (OPINION).
- Fit: uses build skill + HR domain; conflict risks above.

## Gate 2
- Playbook: P7 (productised service, then productise); arguably P2.
- Real case: LeftClick (Nick Saraev), AI/no-code automation agency, $100k/month CLAIMED (services-agencies.md). Designjoy, fixed-price productised service, $1m+ CLAIMED.
