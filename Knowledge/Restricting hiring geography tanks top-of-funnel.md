# Restricting hiring to one geography tanks top-of-funnel before it can be measured

Months of London-only hiring focus for engineering roles produced a thin pipeline (1 platform engineer candidate after withdrawals, backend barely at 4 pair programmings/week). The constraint wasn't visible in weekly metrics because recruiters were hitting activity targets — the damage was in response rates and candidate quality, not effort.

When Benji approved EU/UK remote hiring on 2026-06-29, Ryan predicted response rates would triple. The unlock happened only after Ryan and Owen presented a data brief showing the pool size problem — the policy didn't self-correct from metrics alone.

**Implication:** Geographic hiring restrictions need an explicit review trigger (e.g. "if pipeline < X after N weeks, revisit geography"). Relying on weekly activity metrics masks the constraint because recruiters compensate with volume.
