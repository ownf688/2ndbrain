# Earn Your Spot

Performance management framework and manager handbook initiative. NALA as an "athletics team" — continuous assessment on performance (skills + impact) and values, with disproportionate rewards for top performers and clear exit paths for underperformers.

Owned by [[Me]] with [[Lynnette Mutugi]] as key partner.

## Quality framework

| Bar | Definition |
|-----|-----------|
| **Great** | Framework documented and shared with Benji for CEO sponsorship; rubric clear enough for managers to self-serve; first calibration session scheduled; Windmill feedback adoption rising |
| **Good** | Core framework (matrix, rubric, reward model) drafted and shared with Lynnette; working sessions producing tangible output; manager training plan scoped |
| **Mediocre** | Conceptual direction set but no tangible documentation managers can use; working sessions not happening; Windmill adoption still at 2 people giving feedback |
| **Bad** | No progress on framework; Q3 passes without manager training; next performance cycle runs with same gaps as last time (vague assessments, no evidence, scoring-for-pay) |

### Notes on use

- This is a Q3 priority — "Bad" means Q3 ends without deliverable progress
- CEO buy-in is a prerequisite for success, not a nice-to-have
